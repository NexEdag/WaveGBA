**WaveGBA —— 装在口袋里的 Game Boy Advance 模拟器**

WaveGBA 是一款基于 vba-next 优化版核心的 GBA 模拟器，提供 Android 端实现。项目由 Edag 开发并维护。

项目的设计目标是提供一个轻量、无广告、且具备完整游戏管理能力的 GBA 模拟环境。模拟核心沿用成熟实现并对其渲染路径做了针对性优化，上层则围绕"长期游玩"而非"临时试玩"组织功能。

**一、游戏库**

应用启动后首先呈现游戏库，而非文件选择器。每个条目包含封面、游戏名称与上次运行时间，按最近游玩排序，支持重命名与移除（移除仅删除库记录，不影响 ROM 与存档文件）。

封面在首次添加时生成为确定性渐变标识，退出游戏时自动替换为最后一帧实际画面。

添加游戏时，ROM 会被复制至 `WaveGBA/ROMs/` 并以此副本作为唯一读取源。该设计避免了对外部应用临时授权的依赖，ROM 被移动或删除后仍可正常运行；相应代价是占用一份额外存储空间。此外支持选择文件夹批量扫描（含 zip 内 ROM，按 CRC32 去重），搜索支持名称、编号与拼音首字母，收藏条目置顶。

**二、主要功能**

- **宏（输入录制与回放）**：录制操作序列后可逐帧回放，支持循环播放与文件存取。输入采样与模拟帧同步，因此回放不因帧率波动产生偏移。
- **连发键**：可对 A / B / L / R / START / SELECT 及方向键分别启用自动连打，速率 5～30 次每秒可调，启用状态在按键上以标识点显示。
- **按键布局编辑器**：支持逐键拖动定位、全局尺寸（60%～180%）与透明度（25%～100%）调节，横屏与竖屏配置独立保存。
- **屏幕录制**：输出 H.264 / MP4 至 `WaveGBA/Videos/`，采样 30fps，可选是否包含音轨；设备不支持硬件编码时自动降级为 MJPEG / AVI，并在开始前提示。
- **存档导出与导入**：将电池存档与全部即时存档槽位打包为 zip，经由系统分享导出；导入时自动解压至当前存档目录并重新加载电池存档。

**三、常规功能**

即时存档 10 槽位（带画面缩略图，另设 SAVE / LOAD 独立快速槽位）；屏幕方向切换（自动 / 横屏 / 反向横屏 / 竖屏 / 反向竖屏）；倍速 0.5x～64x（8x 以上因核心音频缓冲限制自动静音，跑不到设定值时显示实际倍速）；快进键（点击切换，位置可拖动并记忆）；音量调节；画面缩放三档（适应屏幕 / 整数缩放 / 拉伸铺满）；画面边框（GBA 机身 / 渐变）；画面滤镜（LCD 网格 / 扫描线）；亮度调节（60%～140%）；主题配色（5 套预设 + HSV 色盘自定义）；一键截图；按键显示；游戏信息（读取卡带头获取编号、厂商、版本、地区）；实时时钟（RTC，默认开启）。

存档统一存放于 `/sdcard/WaveGBA/Save/`，电池存档裁剪为标准尺寸（512B / 8KB / 32KB / 64KB / 128KB），可被 mGBA、MyBoy 等主流模拟器直接识别。

**四、平台与版本**

- 当前版本：1.1.1（versionCode 111）
- 安装包体积：990 KB
- 支持平台：Android

**五、已知限制**

- 暂未提供金手指功能（需修改核心层以暴露内存接口）
- Android 11 及以上需授予"所有文件访问权限"方可写入公共目录，未授权时自动回退至应用私有目录
- 尚未进行完整的真机兼容性测试
